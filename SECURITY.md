# Security policy

## Supported versions

Safro is an early reference implementation. Security fixes are made on the latest `main` branch; no released versions are supported yet.

## Reporting a vulnerability

Do not report vulnerabilities involving funds, private keys, settlement integrity, authentication, replay attacks, or data exposure in a public GitHub issue.

Use GitHub's private security advisory feature for this repository, or contact the repository owner through a private channel. Include a clear description, affected code paths, reproduction steps, impact, and any suggested mitigation.

Please allow time for triage and remediation before public disclosure.
