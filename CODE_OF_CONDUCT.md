# Code of conduct

Safrod follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want participation to be harassment-free and respectful for everyone, regardless of background or experience. Expected behaviour: be considerate, assume good faith, give and accept constructive technical criticism, and focus on what is best for the project and its users. Unacceptable behaviour: harassment, discrimination, personal attacks, publishing others' private information, and other conduct that would reasonably be considered inappropriate in a professional setting.

Maintainers may remove comments, commits or contributions that violate this code and may restrict participation. Report concerns privately to the maintainers through GitHub (a private security advisory or a message to a maintainer); do not use public issues for conduct reports. Reports are handled in confidence.
